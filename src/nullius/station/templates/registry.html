the same rule, at two scales

The analysis plan is hashed and committed before the ladder that tests it exists, so the git history is the evidence that the plan predates the results rather than a docstring claiming it does. One level down, each experiment's design is hashed and locked before its first run, and a trigger refuses a run that has no prior locked registration.
